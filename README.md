# FileFlip — Free PDF & Image Tools Online

FileFlip is a free web-based file utility platform designed to make everyday PDF and image tasks simple, fast, and accessible.

The project provides browser-based tools for converting, compressing, and combining files without requiring users to create an account.

## Live Website

https://feranmi-codes.github.io/FileFlip/

## Features

FileFlip currently provides:

* PDF to JPG/PNG** — Convert PDF pages into JPG or PNG images.
* JPG to PDF** — Convert and combine JPG, PNG, and WebP images into a PDF.
* Compress PDF** — Reduce PDF file size using different compression levels.
* Merge PDF** — Combine multiple PDF files into one document.

## Privacy-Focused Processing

FileFlip is designed to process conversion tasks directly in the user's browser whenever possible.

This means files used with the conversion tools do not need to be uploaded to a FileFlip server for processing.

FileFlip does not require users to create an account to use the available tools.

## How to Use

1. Visit the FileFlip website.
2. Select the tool you need.
3. Upload your file or files.
4. Choose the available options.
5. Start the conversion or file operation.
6. Download the resulting file.

No account is required.
